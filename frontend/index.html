Insights

Hotspots with the most dependencies, dependency cycles and file counts per layer.

Risk report

History and dashboard

How it works

Three steps, about a minute.

  1. Add a repository
    Paste a public GitHub URL or upload a ZIP.
  2. Choose options
    Include external dependencies, detect risks, generate a summary.
  3. Read the results
    Switch between diagram, tree, insights and summary.
